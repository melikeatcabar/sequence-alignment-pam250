# PAM250 Matrix & Needleman-Wunsch Global Alignment

Course project — BENG451 Bioinformatics, Gebze Technical University, Spring 2026

## What this project does
- Constructs a PAM250 amino acid substitution matrix from Dayhoff's raw mutation count data
- Implements the Needleman-Wunsch global sequence alignment algorithm from scratch
- Benchmarks alignment results against Biopython's Bio.Align outputs

## Tools
Python · NumPy · Matplotlib · Biopython (sequence retrieval only)
